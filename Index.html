HTML vs HTML5

Full Stack Development Lab Assignment

Aim Theory Differences Examples Demonstration

1. Aim

To differentiate between HTML and HTML5 in terms of features and usage, and demonstrate good and bad HTML using a web page.

2. Theory

HTML

HTML stands for HyperText Markup Language. It is used to create the structure of web pages using elements such as headings, paragraphs, images and links.

HTML5

HTML5 introduced modern features such as semantic elements, audio and video support, canvas graphics, and improved form controls. Modern HTML is continuously maintained as a living standard.

3. Difference Between HTML and HTML5

Feature Earlier HTML HTML5 / Modern HTML
Doctype Longer declarations in older versions <!DOCTYPE html>
Semantic Tags Greater use of generic elements header, nav, main, article, footer
Audio and Video Often used external plug-ins Built-in audio and video elements
Graphics Often required external tools Canvas and SVG support
Forms Fewer built-in input types Email, date, number and required
Character Encoding Longer declarations were common Simple UTF-8 declaration
Usage Older and legacy web pages Modern websites and web applications

4. Good HTML and Bad HTML

Good HTML

Uses semantic tags and proper structure.

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport"
    content="width=device-width, initial-scale=1.0">
    <title>College News</title>
</head>
<body>
    <header>
        <h1>College News</h1>
    </header>

    <nav>
        <a href="#news">Latest News</a>
    </nav>

    <main id="news">
        <article>
            <h2>Tech Fest</h2>
            <p>The event starts Monday.</p>
        </article>
    </main>

    <footer>College Information</footer>
</body>
</html>

Bad HTML

Uses generic tags and poor structure.

<html>
<body>
    <div>
        <font size="6">
            College News
        </font>
    </div>

    <div>Latest News</div>

    <div>
        <font size="4">
            Tech Fest
        </font>
        <br>
        The event starts Monday.
    </div>

    <div>College Information</div>
</body>
</html>

Why is good HTML better?

  • Semantic tags describe the purpose of each page region.
  • Proper headings improve readability and organization.
  • Metadata helps browsers interpret the document correctly.
  • CSS should be used for styling instead of obsolete tags like font.
